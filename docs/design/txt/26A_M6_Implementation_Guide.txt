26A ­ M6 POS & Offline: Implementation Guide

Everything the till track needs: the Android project structure, the local database as Room
schema, the issuance transaction, the sync worker, snapshot application, the scan layer,
the peripheral layer with its simulator, the receipt renderer, sessions and PIN, modes
and training, telemetry, the central-side package, tests including the power-loss harness,
and the tickets. Self-contained; restated material is marked.

Read this first. Build in this order and do not skip ahead: (1) the local database and the issuance transaction with the
power-loss harness, (2) the sync worker against the central simulator until the thirteen conformance cases pass, (3)
the sales screen on the simulator peripherals, (4) real peripherals, (5) shop mode, (6) everything else. A till that sells
beautifully but loses a receipt on a power cut has failed; a till that syncs perfectly but takes five taps to sell will be
worked around with a paper book.

Restated from doc 32 §3, 5, 6, 7 and 19A §8. A WorkManager periodic job (15 min) plus an immediate run after
any issuance when online and on connectivity change; never blocks the UI.

// sync/UploadWorker

loop while outbox.hasUnacked():

   batch = outbox.nextBatch(maxEvents = 500, maxBytes = 2MB, fromSeq = syncState.lastAckedSeq + 1)         //

      contiguous, never splits a bundle

   resp = api.postBatch(deviceId, Batch(batchId = UUIDv7(), firstSeq, lastSeq, appVersion, snapshotVersion,

      clock, uptime, events, engineVersion))

   when (resp) {

      is Ack -> { outbox.markAcked(upTo = resp.lastAppliedSeq, at = now); syncState.lastAckedSeq =

      resp.lastAppliedSeq

                  handleInstructions(resp.instructions); clockOffset = resp.clockOffsetMs;

                  noteOutcomes(resp.outcomes) } // QUARANTINED -> local anomaly audit

      is SeqMismatch(expected) -> { if (expected <= syncState.lastAckedSeq + 1) { resendFrom(expected) } else {

      localAnomaly("gap_ahead"); stop } }

      is Conflict409 -> backoff(); break                                           // another batch in flight (should

      not happen; single worker)

      is RateLimited(retryAfter) -> delay(retryAfter); continue

      is Auth401_403(revoke?) -> { if (revoke) executeRevoke(); stop }

      is Floor426 -> { syncState.floorState = REFUSED; stop }

      else -> backoffWithJitter(5s..10min); break

   }

outbox.purge(ackedBefore = now - 7.days)

// peripherals/ScanLayer.parse(raw: RawScan): ScanResult
sym = raw.symbology ?: detect(raw.data)
when (sym) {

    EAN13, EAN8, UPCA -> ScanResult(sym, gtin = normalize14(raw.data))
    GS1_128, GS1_DATAMATRIX, GS1_QR -> { ais = Gs1.parse(raw.data /* element string or Digital Link URI */)

               ScanResult(sym, gtin = ais["01"], lot = ais["10"], expiry = ais["17"]?.toDate(), weightKg =
                      ais["3103"]?.let { it / 1000.0 }) }

    INTERNAL_20_29 -> { code = raw.data.substring(2, 8); tail = raw.data.substring(8, 12)
               when (prefix) { in 20..24 -> ScanResult(sym, code = code, weightKg = tail / 1000.0); in 25..29 ->
                      ScanResult(sym, code = code, batchRef = tail) } }

}
