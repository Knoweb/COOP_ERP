Cooperative Retail and Distribution System
03  -  Document State Machines
Baseline requirements package  --  document 3 of 10
This is the highest-value artifact in the package. The system is, at its core, a set of document lifecycles  --  this document defines every one of them precisely enough to build against.1. Governing rules (apply to every state machine below)
 Immutability: a document is final at issuance and is never renumbered, edited, or deleted. Correction is always a new, linked document.
 Void != delete: a voided document keeps its number; void is a status, not a deletion.
 Drafts consume no numbers: a document has no number until it is actually issued or printed. Parked or abandoned drafts consume no series position.
 Every transition is audited: every state transition that is privileged (override, approval, reversal) is written to the immutable audit trail with the acting user and role.
