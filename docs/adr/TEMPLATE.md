# ADR-NNN — Short title in the imperative

- **Status:** proposed | accepted | superseded by ADR-MMM
- **Date:** YYYY-MM-DD
- **Mirrors:** doc 09 entry ADR-NNN (or "new; to be entered in doc 09 at its next revision")
- **Raised while:** ticket or document that needed the decision (for example `S0-04`, `docs/change-requests/CR-024-1.md`)

## Context

One paragraph: the situation and the constraint that forces a choice. Cite the document and section that leaves the point open (for example "17A §7 names Gradle but not the version catalogue plugin").

## Decision

One paragraph, present tense: what we do. Name the exact version, library, value or rule.

## Consequences

Two or three sentences: what becomes easier, what becomes harder, what must change if the decision is reversed. If a `docs/DECISIONS_PENDING.md` item is closed by this ADR, name its id and update that file in the same commit.
