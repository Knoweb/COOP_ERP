It takes its module list from the scaffolder, and a test keeps that list equal to `ArchitectureTests.SCHEMA_OWNERSHIP` and to what `FlywayConfig` migrates. `tools/checks.test.mjs` (21 tests, in `make test`) breaks each rule on purpose.
