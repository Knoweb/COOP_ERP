- **S0-11 pipeline (19 Sep, branch `feat/s0-11-pipeline`).** The workflow is rewritten on two rules: a job does real work or does not exist, and jobs call the make targets developers run. Fixed: the stale-client check could never fail (it diffed without regenerating) and is now `make check-generated`, which also covers the Modulith module diagrams, now committed under `docs/modules` as 17A §5 says and emptied before each generation; the "E2E" and "Publish" jobs only printed text and reported green, so "E2E" is replaced by `stack-smoke` (`make up-2`, then the new `tools/smoke.mjs`: health, web, a token with scope claims for each dev user, scope isolation, federation view, registration in UTC, a translated problem, the idempotency key, and nginx alternating between two instances) and "Publish" is removed until a registry exists; web tests were never run and `pnpm lint` called a tool that was not installed, so ESLint 9 is configured (its first run found one `any`) and a Vitest suite checks that every web message id exists in three languages with the same placeholders; the package job now builds the Jib image (`make image`), the web bundle, the shared engine and a CycloneDX bill of materials (139 components), keeping the image only for `main`; the nightly runs `make reset`, `make up`, `make smoke`, `make test`, can be started by hand, prints container logs on failure and always stops the stack; Node 24 everywhere; superseded runs of a pull request are cancelled; till steps no longer skip themselves silently. Checked with actionlint, and every command the jobs call was run on the build machine, including `make smoke` failing when one of two backends was stopped and `make check-generated` failing on a changed slice. `tools/check-generated.ps1` and `tools/gen-clients.ps1` are gone: the make targets work from PowerShell.
