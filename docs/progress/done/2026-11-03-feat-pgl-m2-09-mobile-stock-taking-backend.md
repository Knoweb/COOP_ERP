- **Mobile Stock-Taking Backend (PGL-M2-09, branch `feat/PGL-M2-09-mobile-stock-taking-backend`):** implemented mobile stock-taking backend support in M5 Inventory for warehouse and shop audits; added database migration `V0021__mobile_stock_take_scans.sql` creating table `inventory.stock_take_scan` (scan_id, task_id, owner_entity_id, location_id, scanned_code, sku_id, batch_id, condition, counted_qty, scanned_at, scanned_by, device_id, notes, created_at) with 4-class RLS policies (`own_read`, `own_write`, `fed_view`, `ext_view`) and insert-only permissions for `app_rw`; implemented single scan ingestion command `RecordStockTakeScan` (`RecordStockTakeScanHandler`) with barcode lookup fallback to SKU code, automatic lot and batch resolution, strict idempotency deduplication by `scan_id` (identical re-send returns duplicate flag without double-counting; conflicting retry throws `m5.stock_take.scan_conflict`), audit recording `STOCK_TAKE_SCAN_RECORDED`, and domain event `StockTakeScanRecorded`; implemented offline batch sync command `BatchStockTakeScan` (`BatchStockTakeScanHandler`) accepting queued scan payloads with summary counters (processed, duplicates, total) and domain event `StockTakeBatchScanned`;
