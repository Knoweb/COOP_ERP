- **S0-10 local environment (19 Sep, branch `feat/s0-10-local-environment`).** Built on the compose skeleton of pull request 15. `infra/compose/compose.yml` now runs PostgreSQL 16 (ICU locale provider, volume, init script), PgBouncer in transaction pooling, RabbitMQ, MinIO with the four buckets of 17A §10 (`audit-anchors` with object lock), Keycloak importing `realm-dev.json` (realm `coop`, client `coop-erp-web` with PKCE, users `fed-admin`, `mpcs-admin`, `cashier`, password `dev`, in English, Sinhala and Tamil), Mailpit, the backend and the Vite web client, all with health checks and pinned image versions. `compose.two.yml` and `nginx-two.conf` add a second backend behind nginx. The backend image is built by Jib (`make image`). The Makefile targets `image`, `up`, `up-2`, `down`, `reset`, `migrate`, `seed`, `build`, `test` and `gen-clients` are real; `tools/gen-clients.sh` generates a client for every slice. Three database users replace the superuser login: `postgres` for the init script and seeds only, `coop_migrator` (owns the database, used by Flyway, direct connection) and `coop_app` (member of `app_rw`, used by the application through PgBouncer), so row-level security now applies to the application. Hello sample rows are in `seed/hello/greetings.dev.sql`. Verified on the build machine from an empty state: `make up` and `make up-2` pass; every service healthy; the application user sees no greeting without a scope and is refused an UPDATE; each dev user obtains a token carrying `ent`, `cls`, `lang` and `roles`; six requests through nginx split three and three between the instances; `make down` and `make reset` behave as documented. README carries the fifteen-minute start.
