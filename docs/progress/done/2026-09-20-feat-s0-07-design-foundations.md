- **S0-07 web shell, step 4 of 5: design tokens, bundled fonts, the first three components (20 Sep, branch `feat/s0-07-design-foundations`).** `web/src/design/tokens.css` is doc 30 section 2.1 as CSS custom properties and nothing else (`:root` is its only selector, and a test says so): the one type scale 12/14/16/20/28/40 px (40 for money totals only), line height 1.5 everywhere including headings (Sinhala and Tamil stack marks), two weights (400, 600), the 8 px grid (`--space-1` to `--space-8`, 4 px as `--space-half`), targets of 48 px with 12 px between them, neutral surfaces, ONE accent (`#1b5e20`), a text and a background colour for each of draft, issued, disputed, void and alert, and a training colour used for nothing else. Lengths are rem (a user's larger browser font enlarges the screen, not only the letters), hairlines px. **Contrast is a test, not a promise:** `design/contrast.ts` lists the 21 foreground/background pairs a screen may use, and `design/tokens.test.ts` computes the WCAG 2.2 ratio of each from the real file; a colour token that is in no pair and not on the short "decorative" list (`--color-border` only) fails too, so a new colour cannot escape the check. Measured: text 14.76:1 on the page and 13.53:1 on the subtle surface, muted text 6.46 and 5.92, control edges 4.83 and 4.43 (need 3), accent 7.87 and 7.21, white on accent 7.87, chips draft 7.56, issued 6.93, disputed 6.24, void 8.66, alert 6.21 (alert text on the page 7.33), white on training 9.39; shown to bite by lightening the muted grey (2.50:1, three pairs named). No dark theme: doc 30 asks for none and every pair would need its own check. **Fonts:** Noto Sans, Noto Sans Sinhala and Noto Sans Tamil from the npm packages `@fontsource/*` 5.3.0 (OFL 1.1), imported in `design/fonts.css` and served from our own bundle; nothing is fetched from a third party at run time. Weights 400 and 600, one subset per package (latin, sinhala, tamil); Latin letters and all digits come from Noto Sans, the first name in `--font-ui`, which also keeps digits of one shape in three languages. `pnpm build`: `dist/` 431,531 bytes before, 784,834 after; of the difference the six woff2 files are 131,128 bytes (Latin 26.6 kB, Tamil 30.1 kB, Sinhala 74.4 kB for both weights) and their six woff fallbacks 193,828 bytes that no current browser requests (the packages' CSS names both; dropping woff means writing the `@font-face` rules ourselves: not done, it costs disk on the server and nothing on the wire). No `Intl.NumberFormat`, so no browser can choose Sinhala or Tamil digits or lakh grouping. Accepts `string | number` (a number through `String()`, exponent forms refused); `-0.00` shows as `0.00`; anything that is not a plain decimal (`abc`, `NaN`, `null`, `1,234.00`, `1e3`, non-Western digits) gives a dash with the spoken text "Amount not available", never `NaN`, never an exception. A negative amount shows U+2212 and is read out as "minus Rs 250.00", because screen readers disagree about the sign and some skip it.
