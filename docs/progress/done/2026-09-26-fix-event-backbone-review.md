- **Event backbone, the review fixes (26 Sep, branch `fix/event-backbone-review`).** The review of #86, #87 and #88 found the payload word list half applied and poison messages lost. **Payload**: `OutboxWriter` checks every field of every event, nested objects and arrays included, with the whole-word rule `DeviceEventWriter` already used, so `customerName`, `email`, `mobile`, `address` and `token` are refused; an identifier or a code (`addressId`, `cityCode`) passes unless its head is a secret (`pinCode`), and so do the catalogue display names doc 18 permits (`nameEn`, `nameSi`, `nameTa`, `uomName`, `productName`). The after-commit listeners run from one synchronisation per transaction, and a failing listener is logged, not thrown. **Dead letters**: consumer queues are declared with `x-dead-letter-exchange ""`, `x-dead-letter-routing-key domain.dlq` and `x-delivery-limit 10`; a `PoisonMessageException` (a consumer/type nobody registered, an envelope without owner or correlation, an envelope that cannot be read) or an unreadable body goes to `domain.dlq` with its reason at once; a handler retry, and any other failure, is requeued in place after a growing backoff, so per-source order holds and the delivery limit ends what never passes. RabbitMQ keeps an existing queue's arguments, so a compose stack needs `make reset`. **Relay**: a relay takes the first unpublished source whose advisory lock it gets, and marks by `(received_at, event_id)`; `Replayer` pages by `source_seq`. **Inbox** (`kernel/V0032`, lane B): a claim carries the scope entity and `app_rw` sees and writes only its scope's claims (`own_*` of the template, no location line). **Idempotency**: a retention window under 24 hours is refused at start. **Deviations**: testsupport has no RabbitMQ container, so the broker-level poison and order test is deferred and the runtime is proved with a mocked channel; the partition job still runs on every role, because a web-only instance needs today's partition; inbox retention and the idempotency of non-HTTP callers (K-08 and K-12 pass their own key) are deferred. **Proof**: `OutboxWriterForbiddenFieldsTest`, `OutboxPayloadValidationPostgresIntegrationTest`, `RabbitConsumerRuntimeTest`, `EventConsumerFrameworkPostgresIntegrationTest`, `OutboxRelayLockPostgresIntegrationTest`, `JdbcIdempotencyStoreWindowTest`, and the event, idempotency, notification and policy suites.
