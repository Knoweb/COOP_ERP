- **S0-06 OpenAPI-first toolchain, server side (19 Sep, branch `feat/s0-06-openapi-server-generation`).** The web client half existed; the server half did not, so the hello controller was written by hand against its slice. Now openapi-generator 7.25 (generator `spring`, interfaces only) runs in the Gradle build: one task per slice, found automatically, so a scaffolded module needs no build change. Each slice yields `<Tag>Api` and its request and response classes in `<module>.web.generated`, as build output that is neither committed nor edited, with an `Instant` for date-time, plain nullable fields for the 3.1 `[string, 'null']` types, no Swagger dependency, no generation timestamp and no default method bodies. `HelloController implements HelloApi` and has no mapping annotations; proved that an operation added to the slice fails compilation until the controller has it. `kernel.api.CurrentScope` is new: generated method signatures have no room for a scope parameter, and the design names no way for a controller to read the request's `ScopeContext`; the header-based argument resolver of S0-12 is replaced by its stub `DevCurrentScope`. What every slice shares moved to `openapi/common.yaml` (the Idempotency-Key header, the `Problem` document, the 400 and 422 responses) and is referred to, not copied. Two new safeguards, each proved to bite: architecture rule `controllersImplementTheirGeneratedApi` (fixture with hand-written mappings) and `OpenApiSliceRulesTest` (3.1, `/v1/`, unique `operationId`, exactly one tag, `x-permission` everywhere, Idempotency-Key on mutating operations; no key without a value, which is what a comma inside an inline description becomes; a deliberately broken slice must report nine violations). Verified (again on 20 Sep, after the two decisions below were built): 58 unit and 21 integration tests, 22 tool tests, `make check-generated`, `make test-scaffold` in a clean clone (the copy got its own `PricingApi` and passed its 21 inherited tests), and `make smoke` against the running stack with the new Jib image.
