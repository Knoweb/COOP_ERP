- **Sinhala dates use the Gregorian month names; a system batch is not shown by its internal number (28 Sep, branch `fix/sinhala-dates-and-batch-labels`).** Two screen bugs from the 28 September demo. (1) Since #188 added the FormatJS Intl polyfills with si/ta locale data, `useFormatInstant`/`useFormatDate` (`web/src/shell/i18n/formats.ts`) formatted a date through `intl.formatDate({ dateStyle: "medium", ... })`, and si-LK's CLDR data gives the Gregorian calendar's own month names as the *traditional* Sinhala lunar calendar's names (Node ICU 78: `new Intl.DateTimeFormat("si", {calendar: "gregory", month: "long"})` prints "බිනර" for September, "මැදින්" for March), so the screen showed "2026 බිනර 28" for 28 September. Doc 19 section 5.1 fixes the shape platform-wide as `dd/mm/yyyy` with Western Arabic digits (DR-6), the same way the kernel's `IcuFormats` renders the PDF with one fixed `DateTimeFormatter.ofPattern("dd/MM/yyyy")` regardless of locale. Both hooks now build `dd/MM/yyyy` (and `dd/MM/yyyy HH:mm` for an instant) from `Intl.DateTimeFormat("en", {...,calendar:"gregory",numberingSystem:"latn"}).formatToParts()`, so no month-name table and no locale-driven field order is used at all; vitest cases cover si and ta (`formats.test.tsx`). Checked: the backend A4 invoice's dates go through the kernel's `IcuFormats` only, never through this file, so they are unaffected. (2) The GRN lines, the delivery note's batch picker and the stock position (`GrnPage.tsx`, `NewDeliveryNotePage.tsx`, `StockPage.tsx`) showed a batch-less SKU's synthetic batch by its internal number, e.g. "S-OPB-01a0e468-9" for white sugar (M2-05 names a synthetic batch `S-<document>-<line>`, `BatchGuards.syntheticBatchNo`). `GrnLineResponse` and `LotBalanceResponse` carry no `synthetic` flag yet, so the screens recognise the backend's own fixed shape (`isSyntheticBatchNo`, added to `tradingView.ts` and `stockView.ts`) and show the message id `trading.field.batch_not_tracked` / `inventory.field.batch_not_tracked` ("No batch (not tracked)", en/si/ta) instead; a real, printed batch number is shown as it is. Proof: `pnpm lint`, `tsc --noEmit`, `pnpm vitest run` (202 tests), `node tools/check-i18n.mjs`.
