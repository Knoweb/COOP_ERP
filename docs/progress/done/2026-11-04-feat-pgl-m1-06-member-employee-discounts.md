Defined inverted SPI `CustomerClassEligibilityProvider` in `m3pricing.api` implemented by `m7customers` (`MemberEligibilityForPricing`) and `m9integration` (`EmployeeEligibilityForPricing`), eliminating cross-module cyclic dependencies and schema coupling. Extended `shared-engine` `Rule`, `RuleEvaluator`, and `BasketResolver` with customer-class and branch-scoped rule evaluation matching general rules and class/branch-targeted rules under explicit beneficiary credentials (`MEMBER` with `regionalMemberNo`, `EMPLOYEE` with `employeeNo`) and location filters. Extended till snapshot distribution with sanitized `member_discount_eligibility` (`m7customers`) and `employee_discount_eligibility` (`m9integration`) tables strictly excluding NIC, phone, address, attendance, and payroll amounts. Added offline till cashier workflow in `TillController` and `TillApp` supporting `General`, `Member`, and `Employee` beneficiary modes with instant local validation and basket attribution. Added optional `locationId` to `RulePredicate`, `RuleStore`, `RuleVocabulary`, `PricingSnapshotContributor` (filtering offline till sync rules), and web authoring UI in `RulesPage.tsx`. Verified barcode compatibility for scanned member passbooks/cards against case/whitespace-trimmed lookup and SKU barcodes against `m2catalogue`. Added unit and PostgreSQL integration tests across shared engine, pricing rule vocabulary, member/employee providers, branch-scoped rule isolation, snapshot privacy and scoping, and till UI beneficiary scanning.
