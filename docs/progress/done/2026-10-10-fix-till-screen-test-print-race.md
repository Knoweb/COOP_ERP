- **Till screen test print race**: `TillScreensTest` failed once in CI (run 37972567025, PR #323, "Expected value to be true" at the `.bin` count) and passed on rerun. The cause was the test's timing, not the clock: the preview printer writes each slip's PNG and then its `.bin`, and the test waited for the PNGs but counted the `.bin` files once. It also took the sale's PNG as the end of the sale, while the till stays busy (its buttons disabled) until the print returns, and its wait for "Z-report" matched the button just clicked. The test now waits for each slip's PNG and `.bin` together, for the till to be idle after the sale, and for the Z-report panel's title. Reproduced with a 1.5 s pause between the two writes (fails before, passes after); the till's JVM tests pass.
