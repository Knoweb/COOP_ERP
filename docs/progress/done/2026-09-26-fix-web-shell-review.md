- **Web shell, the review fixes (26 Sep, branch `fix/web-shell-review`).** The seven web findings of the review of 26 September (M1-12 part 1). **The step-up replays the command** (doc 19 section 2.2; `shell/api/pendingCommand.ts`, `shell/auth/StepUpReplay.tsx`): a mutation refused with `mfa.required` is kept as plain data (method, address, Idempotency-Key, JSON body; never the token, never a file) in the state of the login request, and after the sign-in the frame of every page takes it again once with the fresh token and the same key, says what became of it, and makes every page re-read; the middleware starts one step-up per page life however many requests were refused at once. The sign-in keeps `prompt=login` (a fresh password sign-in counts on the compose stack, #116) and asks for the second factor with `acr_values` where a realm has one (`VITE_OIDC_STEP_UP_ACR_VALUES`, empty by default). The client sends `X-Scope-Location` when the active scope names a location (the scope context still names none until the switcher exists). **Server-side search of the register** (21A section 8): `listEntities` takes `q` (a prefix of the code, a part of any of the three names, `%`, `_` and `\` escaped as M2's search does; a trading partner searches the directory by name), the register page sends the search box to the server and says "no societies match" only when no page remains. **ReasonCapture starts empty** (`shell.reason.choose`), so the reason in the audit record is the clerk's. **A calendar date is formatted as a day** (`useFormatDate`, UTC, no time): the governance signature no longer shows 5:30 AM. **A read-only class is shown no command** (`shell/auth/permissions.ts`: FEDERATION_VIEW, PARTY and EXTERNAL_TIMEBOXED hold reads only, the rule of 19A section 3's resolver), the two register forms are behind `gov.entity.register`, and the e2e test asserts fed-admin sees the register and no form. **A fact with no value** in `DocumentHeader` is an `aria-hidden` dash plus a visually hidden `shell.fact.empty`, as `MoneyDisplay` does. **Deviations**: the temporary role map stays, below. **Proof**: `client.test.ts` (the command handed to the step-up, one step-up for two refusals, `X-Scope-Location`), `pendingCommand.test.ts`, `StepUpReplay.test.tsx`, `permissions.test.ts`, `components.test.tsx`, `formats.test.tsx`, `router.test.tsx`; `PartyQueriesImplTest` and `EntitySearchPostgresIntegrationTest` (the three languages, the wildcards as letters); the Playwright run through the pipeline's stack-smoke job.
