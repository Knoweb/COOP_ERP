- **CAT-13: import price list lines from a file, with a screen (18 Nov, branch `feat/CAT-13-bulk-price-list-import`).** Added bulk line importer for draft price lists (both TRADE and RETAIL shelf lists) in M3 (Pricing) and Web modules. `POST /v1/pricing/lists/{listId}/import` (`x-permission: prc.pricelist.author`, `x-scope: ENTITY`, `Idempotency-Key` required) parses uploaded delimited sheets (CSV, TSV, semicolon-separated, with quoted cells, comment skipping, and header aliasing) via `PriceListCsvParser` or direct line payloads. `ImportPriceListLinesHandler` executes within a single `@Transactional` boundary, guards draft status and entity ownership, resolves items by SKU UUID, barcode, or SKU code via `CatalogueQueries`, validates prices against authoring rules and gazetted price ceilings via `AuthoringValidator`, replaces or upserts draft lines, records zero-PII audit under `PRICELIST_LINES_IMPORTED`, and publishes domain events `PriceListLinesImported` and `PriceListLinesSet`. Added trilingual backend translation keys in `backend/app/src/main/resources/i18n/m3pricing/{en,si,ta}.json` and frontend keys in `web/src/modules/m3pricing/pricing.messages.json`. In the Web UI, built `PriceListImportModal.tsx` with drag-and-drop file upload, CSV template download, replace/append toggle, row count preview, and validation problem error reporting table; integrated import action into `TradePriceListPage.tsx` and `ShelfListPage.tsx` toolbars. Verified with `PriceListCsvParserTest`, `PriceListImportPostgresIntegrationTest`, `PricingHttpPostgresIntegrationTest`, `PriceListImportModal.test.tsx`, ESLint, and all check scripts (`check-slices.mjs`, `check-permissions.mjs`, `check-i18n.mjs`, Spotless).
