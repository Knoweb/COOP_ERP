- **The web shell and its guards (wave 2: TWK-11 to TWK-18), decided on the architect's delegation (6 Oct, branch `docs/wave2-decisions`), CR-30-2:** (1) **No display name leaves the browser** (TWK-11): the avatar is a `<span aria-hidden>` with initials taken as the first *grapheme* of the first two words (`Intl.Segmenter`, so a Sinhala or Tamil consonant keeps its vowel sign), coloured from tokens; both ui-avatars.com URLs go. (2) **One `businessToday(now?)`** in `shell/i18n/formats.ts` replaces the four module copies and `isoToday` (TWK-12): "today" is today in Colombo for every manager, wherever the browser is. (3) **D-6, the step-up keeps an interrupted command only when it is safe to keep** (TWK-16): its URL must start with the configured `apiBase`, and no key of its JSON body may match the kernel's forbidden-field rule (`OutboxWriter.FORBIDDEN_WORDS` and `SECRET_WORDS`, ported to `shell/api/forbiddenFields.ts` with a test that pins it to the Java list); otherwise the form is shown again with "sign-in was refreshed; enter the details again". `openAccount` (NIC) and anything with a phone are re-asked; an adjustment with a `reasonText` is kept. Rejected: keep everything (personal data in session storage); keep nothing (every step-up loses the clerk's work); encrypt in storage (the key would sit beside it). Doc 30's step-up text gains the sentence at re-issue. (4) `tab.opener = null` after `window.open`, and the tab navigates only to a URL whose origin is the object store's public origin and whose scheme is http(s), through one `openServerFile` helper (TWK-17); the upload's `Idempotency-Key` rotates on an `ApiProblem` only, never on a failed storage PUT, which renews the PENDING row on the same key (TWK-14). (5) **D-9, the build scans what it says it scans** (TWK-15, TWK-18): `moduleStyle` and `moduleFormats` glob `modules/**` and `shell/**`, `.ts` and `.tsx`; `moduleFormats` also catches `new Date()` followed by `getFullYear|getMonth|getDate|toISOString().slice`; a third scan refuses user-visible literals in JSX text (a capitalised run with a space) and in `aria-label`, `alt`, `title`, `placeholder`, with an allow-list that needs a reason in the test file; the eight literals and two `alert()` calls found become message ids with si and ta drafts marked for the translator. A type-based guard (`Money`/`DateOnly` brands) is the better long-term answer and a refactor of the generated clients, not now. (6) A blank or non-decimal shelf price is "incomplete": Save is disabled while any row is incomplete and a `role="alert"` names the rows (TWK-13's web half; the backend rule is in `2026-10-06-wave2-pricing-rules.md`). (7) The Caddy headers, the admin path and `stepUpAcrValues` belong to the deploy kit (`2026-10-06-wave2-deploy-kit.md`); an empty ACR value stays a demo limitation until the realm has an LoA mapping, and no value the realm ignores is set.
