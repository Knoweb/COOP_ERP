- **S0-10 versus 17A §10:** the backend image is built by Jib as 17A says (`make image`, plugin 3.5.4 declared in the root build so all plugins share one Jackson version). One addition: `make image` pulls the base image with Docker and passes `-PjibFromDaemon=true`, so Jib reads the base from the local daemon; on a machine not signed in to Docker Hub, Docker Desktop hands Jib an empty credential and the registry answers 401. CI pushes with `./gradlew :app:jib` and leaves the flag off. Keycloak keeps no data volume, so `realm-dev.json` is re-imported whenever its container is recreated and console changes are not kept. The token claims `ent`, `cls`, `lang` and `roles` are provisional until K-02 defines the mapping of doc 19 §1 (`dev`, `scopes`, `rv`, `mfa_at` are absent); the two development entity ids (`0190f000-…-0001` Federation, `…-0002` an MPCS) are shared by the realm and the hello seed. `make test-int` fails on purpose until S0-12 brings integration tests. `.gitattributes` now forces LF for Makefile, Dockerfile, gradlew, YAML, conf and SQL files. Existing local databases created by the earlier compose file had no volume, so nothing needs migrating; after pulling this change run `make reset` once.
