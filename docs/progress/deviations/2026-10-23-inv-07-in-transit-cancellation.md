- INV-07 Phase 3 treats `physicalReturnVerified=true` on an IN_TRANSIT cancellation as the source user's attestation that every issued line physically returned to the original source; only then does cancellation restore the frozen issued quantities and costs there. This is the narrow safe interpretation of doc 25's “cancel before receipt negates” rule: no stock is restored in response to an unverified cancellation request, and no alternate return destination or partial return is inferred.
