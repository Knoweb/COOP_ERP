- **Scopes are resolved at request time from M1's tables; the provider mapper endpoint of 19A section 2 is not built (raised 25 Sep, pull request #105).** Decided 27 Sep 2026: confirmed (CR-19A-9), on the architect's delegation. Reason: the provider we run has no mapper that calls an endpoint without a provider-specific extension, which AGENTS.md forbids the kernel to depend on; a claim issued for a token's lifetime cannot honour "revocation immediate"; a token that does carry `scopes` or `grants` is honoured as a narrowing of the records. Cost of reversal: the endpoint is the small part, the extension the large one; nothing built here stands in its way.
