- **PRC-03 label-job lifecycle events and audit (21 Oct, branch `feat/PRC-03-shelf-label-printing`, CR-23A-2):** `PrintShelfLabels` audits `LABEL_JOB_CREATED` and publishes `label_job.requested.v1` when it creates the QUEUED row because every command handler must publish and `label_job.rendered.v1` cannot truthfully describe queue creation; the scheduled worker audits `LABEL_JOB_RENDERED` and publishes the specified rendered event (`label_job.rendered.v1`) only after the PDF exists, while a terminal failure audits `LABEL_JOB_FAILED` and uses `label_job.failed.v1`, the separate fact required for its completion handler to obey the same audit/event rule. M8's requested/completed print-run lifecycle is the precedent; no event carries SKU ids, prices, names or failure detail.
