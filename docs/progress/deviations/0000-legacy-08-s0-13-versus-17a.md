- **S0-13 versus 17A:** `make new-module` takes a third argument, `ENTITY` (17A §13 shows `NAME` and `SCHEMA`): without it every table, class and URL of the copy would be named after the schema (`catalogue.catalogue`), and two modules could not coexist because Spring names beans after classes. The copy's permission strings are placeholders (`todo.<schema>.<entity>.register`), because the guides use short codes that cannot be derived (`cat.sku.create`); the build refuses them until they are replaced. `m10procurement` cannot be scaffolded: it has no schema in doc 18 Part F, `FlywayConfig` or the architecture tests.
