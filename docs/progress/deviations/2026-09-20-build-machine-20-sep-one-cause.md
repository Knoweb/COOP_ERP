- **Build machine, 20 Sep: one cause for both faults, probably.** Docker Desktop stopped starting: `listening on unix://C:/Users/.../Docker/run/sailor-ingest.sock: ... The file cannot be accessed by the system` (Windows error 1920), and the same for `docker-secrets-engine/engine.sock`. Windows refuses every unix-socket file on the C: drive, including ones created seconds before; `fsutil reparsepoint query` on them fails the same way, while the `afunix` driver reports RUNNING and sockets on D: work. That is the fault behind the Java selector error too, which is why `-Djdk.net.unixdomain.tmpdir=D:/tmp` cures Java (now set for the Windows user). Docker's socket paths cannot be moved, so the cure to try is a Windows restart; if it returns, look for a file-system filter on C: (antivirus, backup or sync agent) with `fltmc` from an administrator prompt. Two folders were moved aside while trying, and can be deleted after a restart: `%LOCALAPPDATA%Dockerun.stale-*` and `%LOCALAPPDATA%docker-secrets-engine.stale-*`. Never choose "Reset to factory defaults" in Docker's error dialog: it deletes the images and volumes.
