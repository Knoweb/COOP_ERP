- **S0-06 decisions (architect, 2026-09-20):** (1) `kernel.api.CurrentScope` is accepted as a kernel contract addition; the module diagram `docs/modules/module-kernel.adoc` shows it. It is for controllers only: the architecture rule `onlyControllersAskForTheCurrentScope` fails the build for a class outside a module's `web` package that uses it, because a handler that reads the scope of the HTTP request cannot serve a till sync batch or a job. (2) Bean validation is on (this reverses the first S0-06 choice): `useBeanValidation=true`, `spring-boot-starter-validation`. The shape of a request is written in the slice and enforced by the kernel before the controller runs; `RequestValidationHandler` answers 400 `request.invalid` with an `errors` list of `{ field, code, message, params }` whose codes are generic, translated message ids (`request.field.required`, `too_short`, `too_long`, `too_small`, `too_large`, `format`, `invalid`), and 400 `request.malformed` for a body that cannot be read. Reason: with trainees building modules in parallel, a forgotten null check must not become a 500. Business rules, and any rule that must hold for commands that do not arrive over HTTP, stay handler guards. `Problem` in `common.yaml` gained `errors` and the `FieldProblem` schema: a deviation from 17A section 4.4, which shows no field list; raised as `docs/change-requests/CR-17A-1.md`, which also asks for one name (`code`, not `type` as 21A section 5 words it) for the message id. Accepted on 2026-09-20; it stays listed here until 17A is re-issued. Hibernate's own entity validation is switched off (`jakarta.persistence.validation.mode: none`). The Sinhala and Tamil texts of the nine new messages are unreviewed, like the others (QA). (3) For a response defined in `common.yaml` the generator names the class after the operation (`RegisterGreeting400Response`); accepted in exchange for one shared definition instead of nine copies. Bundling the slices first would tidy the names and can be added later without touching a module. (4) 17A names `orval or openapi-typescript` for the web client; openapi-typescript stays (types only). S0-07 decides whether the shell's `api/client.ts` uses `openapi-fetch` inside.
